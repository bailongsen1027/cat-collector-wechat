# 喵星收藏家 · 微信小游戏原型

## 运行
1. 安装微信开发者工具，选择「导入项目」，目录选择本文件夹。
2. 项目类型为「小游戏」。使用测试号体验，或在 `project.config.json` 将 `touristappid` 替换为自己的小游戏 AppID。
3. 点击编译，在模拟器中体验；也可用工具预览到真机。`index.html` 是同一套逻辑的浏览器预览入口，不是微信小游戏入口。

## 已实现
5 个示例关卡、四列前排拿取和盲盒、5–7 个等候槽、每列从下方看到的第一个像素判定、自动派猫和往返动画、堵塞判定、四种可免费体验的道具、图鉴与小鱼干、设备本地存档。飞碟将未完成猫盒送回队列前方，避免丢失与剩余像素对应的数量。

## 原型范围与上线前工作
此版本是离线玩法原型，不是完整商业上线版本：没有 300 关、真实广告/支付、后端、皮肤扭蛋、音效、壁纸分享或正式美术。道具暂不消耗且不接广告；加速持续 8 秒。中途退出会放弃本局，通关图鉴和金币保存在本机。需要接入真实广告位、完善隐私政策和微信审核材料，并按目标设备测试性能和适配。

PRD 中四邻域边缘算法与“每列最下方第一前线”互相冲突，本原型采用后者。示例关卡按从底到顶生成猫盒，支持玩家通过调整选取顺序或飞碟解堵；尚未对所有选择路径做难度或可解性验证。
